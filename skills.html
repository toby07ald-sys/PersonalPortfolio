Technical Skills

Network Architecture & Administration

Focus Areas: Advanced Networking, Network Server Administration, Network Architecture and Operations.

Explanation: I need to understand exactly how networks are built and run before I can figure out how to secure them. This year, I am diving straight into how servers operate, how data travels, and how to configure everything properly.

Context: These are my core second-year modules. But reading about it is not enough, so I am also working through the Cisco CCNA to get hands-on with routing and switching. It helps me connect the theory from my university lectures to actual industry hardware.

Evidence: Year 2 BSc Cyber Security Modules; Cisco CCNA (In Progress).

Linux & Server Administration

Explanation: You cannot really work in cyber security or manage enterprise networks without knowing your way around a Linux command line. It is the operating system that runs the vast majority of servers and security tools.

Context: As part of my Network Server Administration module this year, I am getting deeply hands-on with Linux environments. I am learning how to configure servers, manage user permissions, and navigate the system securely using just the command line instead of relying on a graphical interface. It ties everything I am learning about networking and security together.

Evidence: Network Server Administration Module Work.

Applied Cyber Security & Information Security

Focus Areas: Information Security, Cyber Security, Cryptography, Secure Sockets.

Explanation: This is where things get practical. It is one thing to know data should be protected, but actually building the secure connections or testing how easy it is to crack a hash is completely different.

Context: I am moving away from just theory and starting to build my own tools. Recently, I wrote a Python script to crack SHA-256 hashes using a dictionary attack and the RockYou wordlist. I also built a multithreaded chat server in Java to understand how secure sockets work under the hood.

Evidence: Java Secure Chat Server Repository; Python Hash Cracker Portfolio Project.

Systems Programming: Java

Explanation: Moving from basic scripts to actual software means learning how memory, processes, and networks function together. Java forces you to structure everything properly, which is crucial for building software that does not break under pressure.

Context: For my systems programming coursework, I built a Java-based multithreaded chat server and client application. This was a massive step up for me. It taught me how to handle secure socket connections and manage multiple users talking to the server at the exact same time without the whole system crashing.

Evidence: Java Secure Chat Server Repository.

Python Specialization & Logic

Explanation: Python is the industry-standard language for Cyber Security scripting. I have built a versatile foundation by working with Python (dynamic) alongside Visual Basic (a compiled, strongly typed language), giving me a strong grasp of both modern flexibility and strict structural logic.

Project Management: Agile & Kanban

Explanation: In professional software development, coding is only one part of the process; managing the workflow is equally important. Agile is the industry-standard approach for building software iteratively without errors.

Context: I apply Agile methodologies to my academic and personal projects. Specifically, I utilize Kanban boards via GitHub Projects to break down large requirements. For my NCTX Bus Ticketing project, I used this approach to develop and test individual features, like the authentication logic, before integrating them into the final build.
