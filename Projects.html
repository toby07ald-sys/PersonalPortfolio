Python SHA-256 Hash Cracker

Description: A dictionary-based password cracking tool designed to test the vulnerability of unsalted cryptographic hashes.

Technologies: Python, Hashlib, File Handling.

Project Deep Dive:

  • Dictionary Attack Implementation: Built a mechanism utilizing the RockYou wordlist to systematically brute-force hashed credentials.
  • Cryptographic Integration: Utilized Python's built-in hashlib library to generate and compare SHA-256 hashes efficiently.
  • Security Application: Developed strictly as an educational tool to demonstrate the critical importance of salting passwords in secure database management.

Context: Independent Cyber Security Portfolio Project.
