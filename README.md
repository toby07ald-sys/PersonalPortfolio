## Stuff I've Built
Here are a few of the core projects linked on the live site:

* **Secure Multi-Threaded Chat Server (Java):** A fully functioning server-client chat app. I set this up with a Java ExecutorService thread pool to handle multiple users at once, backed by AES-128 encryption for private messages and SHA-256 salted hashing for the passwords.
* **NCTX Bus Ticketing System (Python):** A command-line application built heavily around Object-Oriented Programming to handle ticketing logic and user routing.
* **SHA-256 Hash Cracker (Python):** An educational dictionary-based cracking script I built that utilizes the RockYou wordlist to crack hashes.
